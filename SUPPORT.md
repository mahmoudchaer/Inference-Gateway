# Support

Use [GitHub Issues](https://github.com/mahmoudchaer/Inference-Gateway/issues) for reproducible bugs and focused feature requests. Include the output of `inference-gateway status`, the gateway version, and your operating system, but remove prompts, source code, API keys, and other sensitive content.

This community project does not provide guaranteed response times or private general-support channels. Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
