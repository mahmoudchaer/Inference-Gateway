# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.1] - 2026-09-23

- Initial public release for macOS Apple Silicon, macOS Intel, and Windows x64.
- Added local Codex routing with automatic restoration on clean shutdown.
- Added Jev-assisted context selection with conservative pass-through behavior.
- Added a local dashboard, configurable logging, self-update, and complete uninstall.
- Added SHA-256 checksums for release binaries.
